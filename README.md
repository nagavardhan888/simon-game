# simon says game
A fun interactive memory game built with HTML, CSS, and JavaScript.
Test your memory skills by repeating the sequence of colors and sounds. Each round gets harder as the sequence grows longer;
Features
Classic Simon Says gameplay with colorful buttons 
Increasing difficulty as you progress through levels
Responsive design for desktop and mobile
Simple, lightweight, and easy to run in any browser
Getting Started
Clone the repository
``
git clone https://github.com/nagavardhan888/simon-game.git
cd simon-game
``
How to Play
Press any key to start the game.
Watch the sequence of colors and sounds.
Repeat the sequence by clicking the buttons in the correct order.
Each round adds a new step to the sequence.
If you make a mistake, the game ends — refresh the page and plaay again
Tech Stack
HTML5 for structure
CSS3 for styling and animations
JavaScript (ES6) for game logic
